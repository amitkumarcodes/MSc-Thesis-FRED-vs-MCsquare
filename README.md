# MSc Thesis: FRED vs MCsquare

This repository contains code and supporting material developed for my MSc thesis in Medical Physics:

**“Comparison of Fast Monte Carlo Dose Calculation Algorithms for Proton Therapy: FRED versus MCsquare”**

The thesis compares two fast Monte Carlo dose calculation engines, **FRED** and **MCsquare**, for pencil beam scanning proton therapy.

## Scope

The comparison includes:

* homogeneous water phantom simulations
* heterogeneous phantom simulations
* comparison of proton range and depth-dose distributions
* lateral dose profile analysis
* investigation of material and beam-model differences
* nuclear-interaction studies
* clinical proton therapy cases
* DVH and dosimetric metric comparisons

## Software

The main dose calculation engines used in this work are:

* **FRED**
* **MCsquare**

Python was used for dose-data processing, analysis, visualization, and comparison.

## Repository status

The repository is currently being prepared alongside the MSc thesis.

Analysis scripts, configuration examples, and supporting material will be added after final thesis submission.

No patient-identifiable data will be included in this repository.
